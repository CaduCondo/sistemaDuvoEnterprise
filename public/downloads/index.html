🚀 Instalação Rápida

  1. Baixar Arquivos

    Clique nos botões acima para baixar todos os 4 arquivos

  2. Criar Pastas

    No seu repositório local, crie:

    scripts\ e .github\workflows\

  3. Copiar Arquivos

    sync-softgen-to-github.bat → scripts\

    sync-softgen-to-github.sh → scripts\

    sync-from-vercel.yml → .github\workflows\

  4. Commit e Push

    git add .

    git commit -m "feat: add sync automation"

    git push origin main

  5. Configurar GitHub

    Settings → Actions → General

    Workflow permissions → ✅ Read and write

  6. Testar

    Actions → "Sync from Vercel (Auto)" → Run workflow
